# 0.1.0 worklog

Implemented sound voronoi experiment in index.html + app.js.

- Voronoi via Bowyer-Watson Delaunay + nearest-pixel cells.
- N input rebuilds points, triangulation, adjacency, greedy pentatonic note coloring, cell areas -> masses.
- Probe launched by drag; gravity integration with softening and wall bounce.
- Audio: Web Audio two modes; nearest + adjacent voices; panning by LR; slider maps distance to volume/freq.
- Mode 1 continuous tones at point pitches; Mode 2 distance->freq with AM rate 0.1..30Hz.

Validation: node --check app.js; triangulation/area sums verified via node eval (400000 px, tris>0).
