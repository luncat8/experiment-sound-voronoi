# 0.2.1 — envelope halos, mass sculpting, and scene links

## review of 0.2.0

The pinned voice pool already supplies the right active-cell mapping, but an
animation-clock oscillator would not track the real LFO as its rate is smoothed,
voices are reassigned, or the audio context is suspended. Chromium also does not
reliably report automated `AudioParam` values through `.value`, so reading the
control parameters alone is insufficient for an instantaneous meter.

## changes

- Added a silent, parallel DC meter to each voice, driven by the same LFO and
  matching envelope/level automation. Reused 32-sample analyser buffers feed
  per-frame envelope and pre-pan/pre-master signal levels; newly claimed slots
  discard the previous analyser window for one frame.
- Drew preallocated, color-matched halos for active sites: radius follows envelope,
  brightness and an inner arc show signal level. Continuous envelopes are steady;
  meters continue while muted and freeze with the audio context when paused.
- Added hover highlighting and mass readout. Wheel up/down changes the hovered
  site's mass and visual radius immediately, with bounded values and normalized
  pixel/line/page deltas. Ordinary scrolling and control-wheel zoom are left alone.
- Added versioned, validated scene URLs in the fragment and a copy button with a
  selectable fallback. Links preserve synth controls, points, masses, tones,
  probe position/velocity, and pause/mute; coordinates scale to the new viewport.
  Empty fields, invalid links, same-page hash navigation, and `file://` are handled.
- Prevented global shortcuts from interfering with text fields, native control
  activation, or modified copy shortcuts. Documented controls and sharing.

## validation

- `npm test` — geometry, physics, tones, existing smoke checks, and new feature
  checks all pass. The new suite verifies slot pinning, meter wiring and buffer
  reuse, halo geometry/brightness, wheel limits and gravitational pull, full URL
  round trips, viewport scaling, empty fields, and clipboard failure paths.
- Headless Chromium with a real Web Audio graph: a 1 Hz envelope meter followed
  the audible modulation (`~0.20..1.00`), envelope-off settled at `1.00` with
  the expected `0.30` signal, and both readings held when suspended.
- Browser interaction check: edited a point, changed all radio groups/sliders,
  copied the real clipboard URL, restored it in another page and via `file://`,
  and checked the mobile selectable-link fallback; no page errors.
- `npm run measure` completed both presets; a 3-second offline render peaked at
  `0.452`, with no clipped samples or silent windows.
